# 이미지 프롬프트 작성

이 역할의 산출물은 이미지 생성 도구에 붙여 넣을 프롬프트와 첨부할 원본 목록이다. 게임 아트의 공통 문구·해상도·Unity 설정은 [게임 이미지 스타일 가이드](../00_Guide/ART-STYLE.md)를 따른다.

## 요청을 프롬프트로 옮기기

1. 화면과 용도를 확인한다. 보드 한 칸, 인벤토리 초상, 액션 시트, 발사체, 팝업 텍스처는 필요한 구도가 다르다. [작업별 문서](../MAP.md) · [로비 디펜스 기획](../01_Architecture/LOBBY-DEFENSE.md)
2. 같은 용도의 게임 PNG를 고른다. 파생 이미지에는 캐릭터 본인의 전신을 첫 참조로, 크롭·시점·시트 배치를 보여 줄 이미지를 다음 참조로 지정한다. [기준 원화 목록](../00_Guide/ART-STYLE.md#기준-원화-고르기)
3. 공통 문구를 복사하고 대상을 구별하는 특징, 바꿀 요소, 방향, 납품 규격을 채운다. 여러 장을 요청받으면 같은 계열에 공통으로 적용할 문장과 각 그림의 지시를 구분한다. [공통 프롬프트와 작성 예시](../00_Guide/ART-STYLE.md#공통-생성-프롬프트)
4. 기존 캐릭터는 종별 색·도구·동작 문구를 재사용한다. 방향이 필요한 침공 몬스터는 해당 시점의 Walk를 Attack의 참조로 쓴다. [개별 문구](../00_Guide/LOBBY-ART-PROMPTS.md) · [침공 방향 표](../00_Guide/INVADER-ART.md#unity에서-재생)

## 전달할 항목

| 항목 | 작성 내용 |
|---|---|
| 사용처·목표 | 화면, 캐릭터 ID, 상태, 축소했을 때 보여야 하는 특징 |
| 참조 원본 | 실제 파일 경로를 첨부 순서대로 적고 각 파일에서 가져올 요소를 지목 |
| 생성 프롬프트 | 공통 스타일 문장과 해당 그림의 구도·프레임별 행동 |
| 제외 요소 | 용도에 맞게 글자, 불투명 매트, 바닥 그림자, 잘린 도구 등 명시 |
| 납품·Unity 적용 | 픽셀 크기, 알파 처리, Sprite 또는 Texture, 시트의 분할·피벗, 필요한 Addressables 주소 |

배경 작업은 보드와 UI가 놓일 영역의 대비를 낮추고, 패널은 제목과 버튼이 올라갈 중앙을 비운다. 이펙트는 발사·접촉·소멸 가운데 어떤 순간을 표현하는지 적는다. [UI 문서](../04_UI/UI.md)
